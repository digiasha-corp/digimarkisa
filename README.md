# Stok Sirup Markisa - Mobile Web App

Aplikasi pencatatan hasil produksi, mutasi barang in-transit 2-step handshake, dan penjualan kasir toko untuk Usaha Sirup Markisa.

## Technology Stack
- Next.js 14 (App Router)
- React & Tailwind CSS
- Lucide React Icons
- Google Sheets API Proxy (`/api/sheets`)

## Deployment
Deployed on Vercel: `https://digimarkisa.vercel.app`
